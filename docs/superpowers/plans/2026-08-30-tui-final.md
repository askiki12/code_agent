# TUI 收尾实现计划（! 命令模式/Ctrl+P 隐藏/skill 弹窗与标注）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Textual 8.2.8**：以安装版本实际 API 为准；若计划代码与 8.2.8 不符，实现者可最小适配并在报告中注明（如 `Screen`/`push_screen`/`OptionSelected.option_list`/模态居中 CSS）。

**Goal:** `!` 命令模式 UI 反馈；Ctrl+P 从 Footer 彻底隐藏；skill 加载标注（`[skill] 加载/✓/✗`）；Ctrl+S 模态技能选择弹窗（选中回车派发、Esc 退出）。

**Architecture:** `on_tool_start` 扩展为 `(name, arguments)`；`_line_style` 补 `[skill]` 样式；`SkillList` 部件 + `PromptInput` 命令模式；`SkillScreen(Screen)` 模态 + `action_choose_skill` + 回调派发。

**Tech Stack:** Python 3.11+，`textual` 8.2.8，`pytest`。测试离线（FakeLLM/假 registry + Textual `run_test`）。

## Global Constraints

- 禁止任何 agent 框架/SDK；改动均在既有 `tui/` 包与 `agent.py` 内。
- `on_tool_start(name, arguments)` 签名扩展（向后兼容性：本迭代刚引入，直接改签名 + 更新全部调用/测试）。
- `!` 命令模式：输入以 `!` 开头 → `command-mode` 类（橙边框）+ placeholder `❯ shell: `；ask 模式不干预。
- skill 标注轻量：`[skill] 加载 <name>…` / `✓ <name>` / `✗ <name>`，不回显全文。
- Ctrl+S 模态弹窗：居中技能列表，回车选中 → 回调派发任务（输入框有值作任务、空则"加载并说明"）；Esc → dismiss 不派发。
- Ctrl+P：`Binding(..., show=False)`（Footer 不显示，按键仍拦截）。
- 凭据纪律不变；测试全部离线；每个任务结束必须测试通过并提交（不 rebase/改写历史）。

```python
class PromptInput(Input):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._ask_mode = False

    def set_ask_mode(self, prompt: str) -> None:
        self._ask_mode = True
        self.value = ""
        self.placeholder = prompt

    def clear_ask_mode(self) -> None:
        self._ask_mode = False
        self.placeholder = "❯ 输入任务（/ 开头为命令）"

    def on_input_changed(self, event) -> None:
        if self._ask_mode:
            return
        if self.value.startswith("!"):
            self.set_class(True, "command-mode")
            self.placeholder = "❯ shell: 输入命令（回车执行）"
        else:
            self.set_class(False, "command-mode")
            self.placeholder = "❯ 输入任务（/ 开头为命令）"
```

```python
class SkillList(OptionList):
    def refresh_from(self, registry) -> None:
        self.clear_options()
        for s in registry.scan():
            self.add_option(Option(f"{s.name}  {s.description}", id=s.name))
```

```python
class SkillScreen(Screen):
    BINDINGS = [Binding("escape", "dismiss", "Cancel")]

    def __init__(self, registry, **kwargs) -> None:
        super().__init__(**kwargs)
        self._registry = registry

    def compose(self) -> ComposeResult:
        with Vertical(classes="skill-screen") as box:
            box.styles.width = "60%"
            box.styles.height = "60%"
            box.styles.border = ("round", "accent")
            yield Static("可用技能（↑↓ 选择，Enter 使用，Esc 退出）", classes="skill-title")
            yield SkillList(id="skill-list")

    def on_mount(self) -> None:
        self.query_one("#skill-list", SkillList).refresh_from(self._registry)

    def on_option_list_option_selected(self, event) -> None:
        self.dismiss(event.option.id)
```

```python
    def action_choose_skill(self) -> None:
        if self._busy():
```

```markdown
## ADR-022：TUI 收尾（! 命令模式/Ctrl+P 隐藏/Ctrl+S 技能弹窗/skill 加载标注）
- **日期**：2026-08-30
- **状态**：已实施
- **背景**：TUI 打磨后反馈：①`!` 输入无命令模式视觉反馈；②Footer 仍显示 ctrl+p disabled；③skill 此前仅工具行样式，无运行标注，且需可查看/选用可用技能。
- **选项**：技能选择右侧边栏（与 Ctrl+L 会话侧栏双面板拥挤/冲突）vs 模态弹窗；skill 标注完整回显 vs 轻量。
- **决策**：`on_tool_start(name, arguments)` 扩展含参；`PromptInput.on_input_changed` 切 command-mode 类+placeholder；`Binding("ctrl+p", ..., show=False)` 彻底隐藏；`[skill]` 行样式（加载品红/✓绿/✗红）；`SkillScreen` 模态（Ctrl+S 打开、↑↓ 选择、Enter 使用、Esc 退出，回调派发"请使用技能 <name>"任务）。
- **理由**：模态避免双面板布局冲突；轻量标注与子智能体一致；show=False 干净移除 Footer 冗余。
- **影响**：TUI 快捷键 +1（Ctrl+S）；`!` 输入有状态反馈；skill 可浏览选用。
```
