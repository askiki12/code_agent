# 子智能体派遣（dispatch_subagent）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 agent 增加 `dispatch_subagent` 工具：父 agent 可派遣一个同步子智能体完成子任务并拿回最终报告；子智能体被 harness 双层强制阉割派遣能力（深度恒 1），保留全部其它工具。

**Architecture:** 在 `agent.py` 内自实现同步嵌套循环——`AgentSession` 新增 `allow_subagent: bool = True` 参数；主 agent 工具列表含 `dispatch_subagent`，子 agent（`allow_subagent=False`）工具列表不含且 `_run_tool` 运行时拒绝；`_dispatch_subagent` 构造子会话（继承 workdir/llm/policy/interact/skills，无 store/workspace）跑 `run_task` 完整循环，只回传最终报告。

**Tech Stack:** Python 3.11+，标准库，无新依赖。测试全离线（FakeLLM mock 模型）。

## Global Constraints

- 禁止任何 agent 框架/SDK；禁止服务端托管工具；重要逻辑自实现。
- `dispatch_subagent` 参数仅 `task`（string，必填）。
- 子智能体 `max_iterations=10`、`max_context_tokens` 同父级；同步串行；无 store/workspace（不持久化）。
- 子会话继承：`workdir` / `llm` / `policy` / `interact` / `skills` / `debug`；`--deny`/`--ask` 对子智能体同样生效。
- 阉割双层强制：子会话工具列表不含 `dispatch_subagent`（不给 schema）+ `_run_tool` 运行时拒绝。
- 返回：子智能体 final_text 直接回传；空报告 `(subagent returned no report; status: <reason>)`；输出经 `truncate()` 8000 截断。
- 凭据纪律不变；工具 schema 以 `docs/tools.md` 为权威源（本迭代同步）。
- 测试全部离线（mock 模型），禁止真实 API key；每个任务结束必须测试通过并提交（保留完整历史，不 rebase/改写）。

```python
    def _dispatch_subagent(self, arguments, on_delta=None) -> ToolResult:
        if not isinstance(arguments, dict) or not str(arguments.get("task", "")).strip():
            return ToolResult(ok=False, output="task is required")
        task = str(arguments["task"]).strip()
        try:
            sub = AgentSession(
                workdir=self.workdir,
                llm=self.llm,
                max_iterations=SUBAGENT_MAX_ITERATIONS,
                max_context_tokens=self.max_context_tokens,
                debug=self.debug,
                policy=self.policy,
                interact=self.interact,
                skills=self.skills,
                allow_subagent=False,
            )
            sub_result = sub.run_task(task, on_delta=on_delta)
        except Exception as e:  # noqa: BLE001 - last-resort guard
            return ToolResult(ok=False, output=f"subagent dispatch failed: {type(e).__name__}: {e}")
        if sub_result.final_text:
            out = sub_result.final_text
        else:
            out = f"(subagent returned no report; status: {sub_result.reason})"
        out, truncated = truncate(out)
        return ToolResult(ok=True, output=out, truncated=truncated)
```

## ADR-018：子智能体派遣（dispatch_subagent，子智能体阉割派遣能力）
- **日期**：2026-08-30
- **状态**：已实施
- **背景**：单循环单上下文无法分解任务，子任务结果全堆父上下文；业界（Claude Code subagent / OpenCode Task）以子智能体编排。用户要求：增加派遣能力，且子智能体阉割此能力、保留其它全部能力。
